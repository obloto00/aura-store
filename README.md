# AuraStore
A lightweight e-commerce storefront built entirely with JavaScript, HTML, and CSS.

## Features
 Standard online shops get repetitive to build, so I added an interactive Fit & Aura Builder: you can drag and drop clothes and accessories onto a virtual mannequin to test out combinations and calculate the overall "aura" score of the outfit before buying.

**Virtual Mannequin & Aura Calculator**: 
 Mix and match tops, bottoms, and accessories to see how they look together and generate a real-time vibe/aura rating. 

## Tech Stack

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
