# AuraStore
A lightweight e-commerce storefront built entirely with JavaScript, HTML, and CSS.

## Features

**Dynamic Storefront**: Responsive product grid and very clean.
**Booking Modal**: Custom pop-up scheduling interface for fitting sessions.
**Testimonial Carousel**: Review slider built with pure CSS transitions and vanilla JS.
**Form Validation**: Client validation with custom error alerts.

## Tech Stack

**HTML5 & CSS3**
**Vanilla JavaScript (ES6+)**
